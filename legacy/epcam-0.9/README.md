# Historical epcam 0.9.0

This directory contains the upstream **epcam** 0.9.0 sources (2009) used as a
protocol/decoder reference for the modern `ep800` driver.

**Do not build these files on current kernels** — they target obsolete V4L1/V4L2
APIs and will not compile.

Original project: https://sourceforge.net/projects/epcam/
